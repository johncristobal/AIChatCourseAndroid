# Genenral notes

The stack I’d pick today
If I were building a new app this week, here’s what I’d reach for. Nothing fancy, but that’s the point.
Kotlin 2.4: The June release stabilized context parameters and explicit backing fields. I’ll give reasons the second one matters below.
Jetpack Compose: The April ’26 release is stable (Compose 1.11). In the XML vs Jetpack Compose holy war, I’d say the case for new screens is settled.
ViewModel + StateFlow: The heart of MVVM Android, and still the safest Android app architecture.
Kotlin Coroutines and Flow: For async work, streams and cancellation.
Room Database: Local storage that flows back out (pun intended).
Hilt: For dependency injection without the ceremony.
Android Studio Panda 4: Planning Mode and Next Edit Prediction are genuinely useful Android Studio tips for big refactorings.
